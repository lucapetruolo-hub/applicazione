# Node.js 26

**Richiesta** (Luca, 23/11/2026, segnalazione #177 "Passare a Node 26: è
uscita la nuova versione stabile", aperta dal controllo giornaliero il
28/10): passare a Node 26 in un thread dedicato.

**Decisione**:
- `.nvmrc` a **`26.13.1`** (ultima 26.x su nodejs.org, correzione di sicurezza
  del 10/11/2026), `engines.node` `26.x` (Vercel passa a Node 26 da qui),
  `@types/node` `^26.6.6` in `apps/web`, `apps/api`, `packages/database`
  (versione uscita da più di 14 giorni). Node 26 è LTS dal 28/10/2026 e
  riceve correzioni fino al 30/04/2029 (Node 24 fino al 30/04/2028). Il
  controllo giornaliero (`.github/workflows/node.yml`) segue da solo la
  versione principale di `.nvmrc`.
- Parte dopo la PR #461 (Node 24.22.3), unita prima per non rimandare la
  correzione di sicurezza.
- **Supporto controllato**: Vercel ha Node 26 per build e funzioni dal
  29/10/2026 (changelog "Node.js 26 LTS is now Generally Available on
  Vercel"); Render installa la versione esatta di `.nvmrc` scaricandola da
  nodejs.org (risolve le versioni con `node-version-alias`), la sua
  documentazione non ha ancora una tabella per la 26; la CI usa
  `node-version-file: .nvmrc` ovunque. Nessuna dipendenza installata
  esclude Node 26 nel campo `engines`.
- **Cose che cambiano con Node 26**: corepack non è più incluso in Node (dalla
  25). Non ci riguarda: la CI usa `pnpm/action-setup`, Vercel e Render hanno
  pnpm loro (`render.yaml` non chiama più `corepack enable` dal §377). Il
  README dice di installare pnpm con `npm i -g pnpm@10.33.0`. Su Vercel il
  `fetch` delle funzioni usa HTTP/2 di serie (Undici 8): l'API su Render lo
  supporta; se servisse tornare a HTTP/1.1 c'è `VERCEL_FETCH_DISABLE_H2=1`.

**Dopo l'unione** (Luca):
1. Render ricostruisce l'API da solo: nel log del deploy deve comparire
   `API in ascolto su 0.0.0.0:… (Node v26.13.1)`. Se il deploy fallisce resta
   in linea la versione di prima (Node 24.22.3).
2. Vercel: in Settings → Build and Deployment → Node.js Version scegliere
   26.x (`engines.node` comunque vince) e fare Redeploy.

dell'API (grafo dei moduli e stream in tempo reale), controllo SEO del sito
privato, codice delle pagine pubbliche, nessun avviso di funzioni deprecate;
